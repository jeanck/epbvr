**epbvr**, a crude featureless single file offline epub viewer.

---

Save/copy the `epbvr.html` somewhere.<br>
Open it on a browser.<br>
Choose an epub file to view.<br>
Refresh/reload to open another file.

---

epbvr uses/includes the [epub.js](https://github.com/futurepress/epub.js) ([license](https://github.com/futurepress/epub.js/blob/master/license)) library,<br>
and the [JSZip](https://github.com/Stuk/jszip) ([license](https://github.com/Stuk/jszip/blob/main/LICENSE.markdown)) library, which uses the [pako](https://github.com/nodeca/pako) ([license](https://github.com/nodeca/pako/blob/master/LICENSE)) library.<br>
The remaining code of epbvr (not already covered by the previous licenses)<br>
is released under the MIT license (see source code lines 119-143).
